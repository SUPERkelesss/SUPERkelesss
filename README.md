## About me

Hi, I'm **kelesss**, a chemistry student at PKU who enjoys building at the boundary between science and software.

- 🧪 Interested in **computational chemistry**, molecular simulation, and reaction-space exploration
- 🧠 Exploring practical ways to connect **chemistry → reaction → machine learning → simulation**
- 🛠️ I care about small, direct designs, typed interfaces, reproducible results, and runtime evidence
- 📚 Maintaining a personal knowledge garden at [kelesss.art](https://www.kelesss.art)
